# New Year Countdown Pro (纯 HTML/JS 版)

这是一个轻量级、无依赖的新年倒计时应用。它使用原生 JavaScript 和 Tailwind CSS (通过 CDN)。

## 本地运行

1. 直接在任何现代浏览器中打开 `index.html`。
   - 双击文件或将其拖入 Chrome/Firefox/Edge/Safari。

## 配置

### API Key (可选)
使用“AI 愿望”功能（由 Google Gemini 提供支持），您需要直接在代码中添加 API Key（因为没有后端或构建步骤）。

1. 用文本编辑器（VS Code, Notepad, TextEdit）打开 `index.html`。
2. 找到这一行：`const API_KEY = "";`（大约在第 140 行左右）。
3. 将您的 Gemini API key 粘贴到引号中。

> **注意：** 由于这是一个纯客户端应用，请勿将包含 API Key 的代码公开托管。

## 功能
- **3 种动态风格**：iOS 极简、未来科技、龙马精神。
- **模拟时间**：您可以穿越时间到午夜附近测试倒计时。
- **AI 愿望**：生成创意的新年祝福。
- **零依赖**：不需要 `npm install`！
